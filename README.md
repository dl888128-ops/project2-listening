# Project 2 — Authentic Listening Lab

Student-facing static listening lesson. Open `index.html` locally or deploy to Netlify/Cloudflare Pages.

## Deploy with GitHub + Netlify
1. Create a GitHub repository and upload `index.html` and `README.md`.
2. In Netlify, choose **Add new project → Import an existing project → GitHub**.
3. Select the repository. For this plain HTML site, no build command is required; publish directory is the repository root (`.`).
4. Deploy and open the generated HTTPS URL. Future pushes to the connected GitHub branch trigger Netlify redeployment.
5. Connect Claude or another AI coding tool to your repository if your instructor specifically requires an AI–GitHub workflow; Netlify's automatic deployment alone does **not** prove AI integration.
